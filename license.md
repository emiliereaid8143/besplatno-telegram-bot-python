### Как создать первого бота

1. Откройте **Бесплатно Telegram Bot Python**
2. Нажмите **"Новый бот"**
3. Введите токен бота от @BotFather
4. Выберите шаблон (начните с "Эхо бот")
5. Нажмите **"Сгенерировать код"**
6. Нажмите **"Запустить"** для тестирования бота
7. Ваш бот уже онлайн!

### Как получить токен у @BotFather

1. Откройте Telegram
2. Найдите `@BotFather`
3. Отправьте `/newbot`
4. Придумайте имя боту (например, "Мой тестовый бот")
5. Придумайте username (должен заканчиваться на "bot", например, "my_test_bot")
6. Скопируйте токен (выглядит как `123456789:ABCdefGHIjklmNOPqrstUVwxyz`)
7. Вставьте токен в инструмент

### Как использовать конструктор кнопок

1. Нажмите вкладку **"Конструктор кнопок"**
2. Добавляйте кнопки в сетку (максимум 8 в ряду)
3. Выберите тип кнопки: URL, Callback, Web App
4. Для URL кнопки: введите ссылку
5. Для Callback: введите данные для обработки
6. Нажмите **"Предпросмотр"** для просмотра
7. Нажмите **"Экспорт кода"** для получения Python кода

### Как создать бота с платежами

1. Выберите шаблон **"Платежи"**
2. Выберите провайдера (Telegram Stars / Stripe)
3. Введите токен провайдера (от @BotFather для Stars)
4. Добавьте товары (название, цена, описание)
5. Нажмите **"Сгенерировать код"**
6. Запустите бота
7. Пользователи могут платить через Telegram Stars

### Как добавить базу данных в бота

1. Нажмите вкладку **"База данных"**
2. Выберите тип БД (SQLite, PostgreSQL, MySQL)
3. Нажмите **"Добавить в бота"**
4. Инструмент автоматически добавит весь код
5. Примеры таблиц: users, messages, settings
6. CRUD операции уже написаны

### Как развернуть бота бесплатно

#### Вариант 1: PythonAnywhere (бесплатно)
1. Нажмите вкладку **"Деплой"**
2. Выберите **"PythonAnywhere"**
3. Нажмите **"Создать скрипт деплоя"**
4. Загрузите скрипт на PythonAnywhere
5. Запустите `bash deploy.sh`

#### Вариант 2: Render.com (бесплатно)
